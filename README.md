# Hi, I'm Santiago 👋

**AI & Data Science student.** I build end-to-end data pipelines — extraction, cleaning,
modeling and visualization — mostly in Python.

- 🔧 I work on ETL: pulling messy data from APIs, CSVs and databases, and turning it into
  fact/dimension models a dashboard can actually answer questions with.
- 🛠️ Python + PostgreSQL day to day, orchestration with **Airflow**, streaming with **Kafka**,
  everything containerized with **Docker**.
- 📈 Currently focused on data engineering and applied machine learning.
